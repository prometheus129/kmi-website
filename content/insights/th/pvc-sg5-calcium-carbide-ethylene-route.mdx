> **สรุป:** PVC จีนส่วนใหญ่ผลิตจาก calcium carbide (ถ่านหิน) PVC ไต้หวัน/ญี่ปุ่นผลิตจาก ethylene (ปิโตรเลียม) ทั้งสองเป็น SG-5 แต่สิ่งเจือปนต่างกัน PVC calcium carbide ใช้ได้ดีสำหรับท่อ uPVC และเปลือกสายเคเบิลสีเข้ม สำหรับผลิตภัณฑ์ใสหรือขาว — ต้องยืนยันปริมาณไทเทเนียมและเสถียรภาพทางความร้อนก่อนเปลี่ยน

## SG-5 เหมือนกัน แต่ทำไมผลลัพธ์ถึงต่างกัน?

คุณกำลังซื้อ PVC SG-5 จาก Formosa ไต้หวันสำหรับผลิตท่อ uPVC ที่โรงงานในระยอง Trader เสนอ PVC SG-5 จีนถูกกว่า $80-120/ตัน K-value เดียวกัน SG grade เดียวกัน คุณเปลี่ยน

ท่อวิ่งดี สียอมรับได้ คุณสมบัติเชิงกลผ่าน แต่เมื่อคุณลองใช้ PVC จีนตัวเดียวกันสำหรับโปรไฟล์หน้าต่างสีขาว — ผลิตภัณฑ์เหลืองหลังจาก 3 เดือนกลางแจ้ง ลูกค้าร้องเรียน

ปัญหาไม่ใช่ PVC จีนคุณภาพต่ำ ปัญหาคือกระบวนการผลิตสองแบบที่ต่างกันให้ผลิตภัณฑ์ที่มีสิ่งเจือปนพื้นฐานต่างกัน — และการใช้งานเป็นตัวกำหนดว่าคุณต้องการแบบไหน

## สองเส้นทางการผลิต PVC ต่างกันอย่างไร — และทำไมสำคัญ?

| | Calcium Carbide Route (ถ่านหิน) | Ethylene Route (ปิโตรเลียม/naphtha) |
|---|---|---|
| **วัตถุดิบ** | ถ่านหิน → calcium carbide → acetylene → VCM → PVC | Ethylene (จาก naphtha cracking) → EDC → VCM → PVC |
| **ผู้ผลิตหลัก** | Sinopec, Tianye (ซินเจียง), Junzheng (มองโกเลียใน), Zhongtai | Formosa FPC (ไต้หวัน), Shin-Etsu (ญี่ปุ่น), Vinythai (ไทย), PT Asahimas (อินโดนีเซีย) |
| **สัดส่วนการผลิตจีน** | ~80% ของ PVC จีน | ~20% ของ PVC จีน |
| **ต้นทุนการผลิต** | ต่ำกว่า (ถ่านหินถูกกว่า naphtha) | สูงกว่า (ขึ้นอยู่กับราคาน้ำมัน) |
| **สิ่งเจือปนเฉพาะ** | ไทเทเนียม (จาก calcium carbide), ปรอทปริมาณน้อย, acetylene ตกค้าง | น้อยกว่า — กระบวนการสะอาดกว่า |
| **สีธรรมชาติ** | เหลืองอ่อนเล็กน้อย | ขาวสว่างกว่า |
| **เหมาะสำหรับ** | ท่อ uPVC, เปลือกสายเคเบิล, ผลิตภัณฑ์สีเข้ม, อัดรีดอุตสาหกรรม | ทุกอย่าง — รวมถึงโปรไฟล์สีขาว, ฟิล์มใส, การแพทย์ |

**80% ของ PVC จีนเป็น calcium carbide route** เมื่อคุณซื้อ "PVC SG-5 จีน" โดยไม่ถาม เกือบแน่นอนว่าเป็น calcium carbide นี่ไม่ใช่ของด้อยคุณภาพ — นี่คือตัวเลือกที่นิยมที่สุดในโลกสำหรับ PVC แข็งอุตสาหกรรม แต่มีข้อจำกัดที่ ethylene route ไม่มี

**สำหรับผู้ซื้อไทย:** Vinythai ผลิต PVC ในประเทศด้วย ethylene route แต่กำลังการผลิตจำกัด PVC จีน calcium carbide เป็นตัวเลือกเสริมที่ราคาแข่งขันได้สำหรับงานอุตสาหกรรมทั่วไป ภายใต้ ACFTA อากรนำเข้า 0% เมื่อมี Form E

## ระบบ SG คืออะไร — ทำไมต้องเข้าใจชื่อ Grade PVC จีน?

PVC จีนใช้ระบบ SG (Suspension Grade) ต่างจากระบบ K-value สากล:

| SG Grade | K-value เทียบเท่า | น้ำหนักโมเลกุล | การใช้งานหลัก |
|---|---|---|---|
| SG-3 | K72-75 | สูงสุด | สายเคเบิล, ผลิตภัณฑ์นิ่มมาก |
| SG-4 | K69-71 | สูง | สายเคเบิล, อัดรีดนิ่ม |
| **SG-5** | **K64-66** | **ปานกลาง** | **ท่อ uPVC, โปรไฟล์, เปลือกสายเคเบิล — นิยมสุด** |
| SG-6 | K60-63 | ปานกลาง-ต่ำ | โปรไฟล์แข็ง, ท่อแรงดัน |
| SG-7 | K57-60 | ต่ำ | ฉีดขึ้นรูปแข็ง, ข้อต่อ |
| SG-8 | K52-56 | ต่ำสุด | ฉีดขึ้นรูปแข็งมาก, ฟิล์มแข็ง |

**SG-5 คิดเป็น ~60-70% ของความต้องการ PVC ในไทย** การใช้งานหลัก: ท่อน้ำ uPVC (สมุทรปราการ, ระยอง), เปลือกสายเคเบิล (Eastern Seaboard), โปรไฟล์หน้าต่าง

## PVC Calcium Carbide ใช้แทนได้ในงานไหน — และงานไหนที่ไม่ควรใช้?

### ใช้ได้ดี (ทดแทน Formosa/Shin-Etsu/Vinythai ได้โดยตรง):

- **ท่อ uPVC** (ประปา, ระบายน้ำ, ร้อยสายไฟใต้ดิน) — การใช้งานใหญ่ที่สุดในไทย ไม่ต้องการใสหรือขาวสนิท Calcium carbide SG-5 วิ่งได้ดีบนสายอัดรีดท่อ Krauss Maffei, Battenfeld, Cincinnati
- **เปลือกสายเคเบิล** (PVC ฉนวน, PVC jacket) — สีดำหรือเทา สิ่งเจือปนไทเทเนียมไม่กระทบคุณสมบัติฉนวนไฟฟ้า
- **ท่อร้อยสายไฟ** (electrical conduit) — ผลิตภัณฑ์แข็ง สีเทา/ขาวขุ่น Calcium carbide ผ่านข้อกำหนด
- **แผ่น PVC แข็ง** (rigid sheet, thermoforming) — สำหรับงานอุตสาหกรรมไม่ต้องการความสวยงามสูง
- **ซีล, ข้อต่อท่อ** — ฉีดขึ้นรูป PVC แข็ง

### ต้องระวัง (ทดสอบก่อนตัดสินใจ):

- **โปรไฟล์หน้าต่าง/ประตูสีขาว** — calcium carbide อาจเหลืองเมื่อสัมผัส UV นาน ต้องเพิ่ม UV stabilizer และ TiO2 pigment ตรวจสอบสูตรก่อนเปลี่ยน
- **ท่อ PVC-U แรงดันสูง** (PN16+) — เสถียรภาพทางความร้อนต่ำกว่าอาจกระทบการแปรรูปที่อุณหภูมิสูง ตรวจสอบด้วย Congo Red test หรือ thermal stability test บน COA

### ไม่เหมาะ (ต้องใช้ ethylene route):

- **ฟิล์ม PVC ใส** (บรรจุภัณฑ์, blister) — calcium carbide ให้ความใสต่ำกว่า เม็ด gel มากกว่า ใช้ Formosa FPC S-65S หรือ Shin-Etsu TK-1000
- **โปรไฟล์สีขาวสนิทกลางแจ้ง** — การเหลืองจาก UV เป็นปัญหาโครงสร้าง ไม่ใช่แค่ความสวยงาม Ethylene route เสถียรกว่า
- **PVC การแพทย์** (ท่อน้ำเกลือ, ถุงเลือด, บรรจุภัณฑ์ยา) — ต้องการ VCM ตกค้างต่ำมากและการตรวจสอบย้อนกลับในห่วงโซ่อุปทาน Calcium carbide ไม่ตอบโจทย์
- **PVC สัมผัสอาหาร** (ฟิล์มห่อ, ถาด) — เหตุผลเดียวกัน: สิ่งเจือปนไทเทเนียมและปรอทปริมาณน้อย

## เปลี่ยนจาก Ethylene เป็น Calcium Carbide PVC แล้วเจอปัญหาอะไรบ่อย?

| อาการ | สาเหตุ | วิธีแก้ไข |
|---|---|---|
| ผลิตภัณฑ์เหลือง (กลางแจ้ง) | ไทเทเนียมใน calcium carbide + UV → สลายตัว | เพิ่ม UV stabilizer (tin stabilizer หรือ Ca/Zn); เพิ่ม TiO2 |
| เสถียรภาพทางความร้อนไม่ดี (ไหม้เร็วเมื่อทดสอบ) | สิ่งเจือปน calcium carbide กระทบ stabilizer | เพิ่มปริมาณ heat stabilizer 5-10%; ตรวจสอบ Congo Red test บน COA |
| Fisheye/เม็ด gel บนผลิตภัณฑ์ | สิ่งเจือปนไม่ละลายใน PVC calcium carbide | เพิ่มเวลาผสม (mixing time); เพิ่มอุณหภูมิ compound |
| Output ลดลงบนเครื่องอัดรีด | Bulk density ต่ำกว่า ethylene route | ปรับส่วนป้อน (feeding section); อาจต้องลดความเร็วสกรู |
| กลิ่นเหม็นเมื่อแปรรูป | VCM ตกค้างหรือ acetylene | ขอ COA ที่ระบุ VCM residual; ระบายอากาศให้ดีขึ้น |

## คำถามที่พบบ่อย

### PVC calcium carbide ปลอดภัยไหม?
สำหรับงานอุตสาหกรรม (ท่อ, สายเคเบิล, โปรไฟล์) — ปลอดภัยและใช้กันอย่างแพร่หลายทั่วโลก 80% ของ PVC จีนเป็น calcium carbide สำหรับงานสัมผัสอาหารหรือการแพทย์ — ไม่แนะนำเนื่องจากสิ่งเจือปนสูงกว่า ethylene route ตรวจสอบ COA และขอใบรับรองความปลอดภัยสำหรับการใช้งานเฉพาะเสมอ

### PVC SG-5 กับ K65 เหมือนกันไหม?
โดยพื้นฐานใช่ SG-5 (ระบบจีน) ตรงกับ K-value 64-66 (ระบบสากล) Formosa S-65 (K65) และ PVC SG-5 จีนมีช่วงน้ำหนักโมเลกุลเดียวกัน ความแตกต่างอยู่ที่กระบวนการผลิต (calcium carbide vs. ethylene) ไม่ใช่ K-value

### ภาษีนำเข้า PVC จากจีนเข้าไทยเท่าไหร่?
0% ภายใต้ ACFTA เมื่อมี Form E ที่ถูกต้อง MFN (ไม่มี Form E): 5% ภายใต้พิกัด HS 3904.10 สำหรับ suspension PVC VAT 7%

### ทำไม PVC จีนถูกกว่า Formosa ไต้หวัน?
สองเหตุผลหลัก: (1) calcium carbide route ใช้ถ่านหิน — วัตถุดิบถูกกว่า naphtha/ethylene โดยเฉพาะเมื่อราคาน้ำมันเกิน $60/บาร์เรล; (2) ขนาดการผลิต — จีนผลิต ~25 ล้านตัน PVC/ปี คิดเป็น ~40% ของโลก ส่วนต่าง CFR มักอยู่ที่ $80-150/ตัน เทียบกับ Formosa ขึ้นอยู่กับช่วงเวลา

### ผสม PVC calcium carbide กับ ethylene route ได้ไหม?
ได้ — และนี่เป็นทางออกสำหรับบางการใช้งานที่อยู่ตรงกลาง ตัวอย่าง: 70% calcium carbide + 30% ethylene route สำหรับโปรไฟล์หน้าต่างช่วยปรับปรุงเสถียรภาพทางความร้อนและทนสภาพอากาศ ในขณะที่ยังลดต้นทุนเทียบกับ 100% ethylene ต้องปรับสูตร stabilizer
